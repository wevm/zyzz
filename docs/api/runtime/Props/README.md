# Props

Small binding helpers used by compiled code.

```ts
import { Props } from 'zyzz/runtime'
```

## Methods

| API                       | Description                                                     |
| ------------------------- | --------------------------------------------------------------- |
| [Props.create](create.md) | Bind compiled classes to the literal styling override contract. |

## Types and Errors

`create.Options`; application types come from root `style`.

See the [public declarations](../../../../src/runtime/Props.ts) for complete generic signatures and documented type properties.
