# Style

Transport opaque static values through component style props without generating CSS.

| API                         | Description                                             |
| --------------------------- | ------------------------------------------------------- |
| [Style.resolve](resolve.md) | Resolve forwarded values into intrinsic element props.  |
| [Style.value](value.md)     | Carry precompiled class metadata in an immutable value. |

Normal authoring uses the root `style` export. These runtime helpers are emitted by the compiler.
