# Comparisons

Compare equivalent workflows rather than syntax alone. The [detailed comparison](../../COMPARISON.md) includes examples and official sources.

- **Authoring:** typed styles, tokens, variants, and dynamic values.
- **Delivery:** compiler requirements, runtime helpers, CSS, and library distribution.
- **Experience:** inference, diagnostics, source maps, and agent readability.
- **Semantics:** cascade, composition, conditions, relationships, and platforms.

Zyzz's documented target includes preview APIs. A design example does not establish implemented parity or measured performance. Use [Compatibility](compatibility.md) and [Benchmarks](benchmarks.md) alongside the comparison.
