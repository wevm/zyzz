# Installation

Choose the path that owns compilation in the application or library.

| Path                                                        | Use                                                                    |
| ----------------------------------------------------------- | ---------------------------------------------------------------------- |
| [Vite](vite.md)                                             | Transform source and deliver CSS within the existing application build |
| [Next.js](next.md)                                          | Integrate source transformation and CSS delivery with Next.js          |
| [CLI](cli.md)                                               | Precompile modules and CSS for a separate build or distribution        |
| [Compiler APIs](../guides/compilation.md#publish-libraries) | Integrate the current literal pipeline with custom tooling             |

CLI and bundler integrations are not yet implemented. Other bundler adapters require their own verified setup; no universal plugin compatibility is promised.
