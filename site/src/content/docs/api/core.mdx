# Core

Define styles, recipes, variables, and configuration with the root `zyzz` entrypoint.

## Authoring

<Card.Group>
  <Card title="style" icon="paintbrush" href="/docs/api/core/style">
    Define a callable style that compiles to static CSS and returns element
    props.
  </Card>
  <Card title="variants" icon="layers" href="/docs/api/core/variants">
    Define finite style choices, defaults, and compound rules for one element.
  </Card>
  <Card title="cx" icon="combine" href="/docs/api/core/cx">
    Combine applied styles in order, keeping their variable bindings and recipe
    attributes.
  </Card>
  <Card title="variable" icon="variable" href="/docs/api/core/variable">
    Declare a typed CSS variable that styles read and assign, statically or when
    applied.
  </Card>
</Card.Group>

## Configuration

<Card.Group>
  <Card title="defineConfig" icon="settings" href="/docs/api/core/defineConfig">
    Bind style and recipe helpers to a variable set, and return the config
    helpers.
  </Card>
  <Card title="defineVars" icon="palette" href="/docs/api/core/defineVars">
    Define a typed variable set of tokens, color pairs, and conditions without
    emitting CSS.
  </Card>
  <Card title="extendVars" icon="copy-plus" href="/docs/api/core/extendVars">
    Override values in an existing variable set while keeping its paths and
    value types.
  </Card>
</Card.Group>
