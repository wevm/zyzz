# Default

Author with Geist colors and typography and Tailwind scales from the opt-in `zyzz/default` entrypoint.

The entrypoint exports the helpers of one bundled config, plus its raw `tokens`. The helpers keep the Core contracts and accept the bundled token names, so no `zyzz.config.ts` is needed. Core imports never load this data.

The package ships a compiled contract beside the module, which the bundler plugins and `Host` from `zyzz/node` read. `style` and `variants` exist only in compiled modules. Font stacks name Geist first, but the application loads the fonts.
