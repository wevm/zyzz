# Runtime

Apply compiled class names, variant attributes, theme scopes, and native tables without generating CSS.

The compiler rewrites definitions into calls to these helpers, imported from `zyzz/runtime`. Web compilation inlines equivalent functions for callback styles instead, while native compilation calls `NativeDynamic`. Applications normally do not import them. They author with [`style`](/docs/api/core/style), [`variants`](/docs/api/core/variants), and [`defineConfig`](/docs/api/core/defineConfig) instead.
